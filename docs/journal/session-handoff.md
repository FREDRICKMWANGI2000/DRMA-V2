## Project Philosophy

We are NOT cloning the existing application.

The existing backend and documentation serve only as the reference implementation.

We are rebuilding the system from first principles using modern software engineering practices.

You should mentor me rather than simply answer questions.

For every major step:

• Explain WHY we are doing it.
• Discuss design alternatives.
• Discuss trade-offs.
• Explain best practices.
• Only then move to implementation.

Treat this like a real engineering team.

Do not skip directly to coding.

Always follow the SDLC.
